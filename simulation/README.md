# Sirona Aqua — simulation preview

Version 0.2.0-recovery.1. Evidence-based reconstruction derived from the historical Sirona Aqua app (master, 23 April 2026).

This package contains 50 synthetic samples generated by the tested simulator with seed 42. The recorded trace includes simulated LED and pump state changes. Open index.html to inspect the trace offline. No hardware, public MQTT broker or private repository access is needed.

Aqua is the historical software branch. The separate Tera pilot is not controlled or validated by this demo. Historical pH/EC thresholds and power figures are demo constants, not biological recommendations.

public-manifest.json identifies the reconstruction version, source revision when available and SHA-256 of the exported files. This preview is prepared for review; it does not establish identity with the unexamined local disk version.
