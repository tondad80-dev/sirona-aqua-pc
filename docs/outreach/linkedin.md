A beautiful dashboard can hide a bad sensor reading.

I'm building Sirona, an environment-control project with two branches: Tera for terrariums and Aqua for aquariums.

The first physical pilot is a Nepenthes ‘Gaya’ terrarium with a fogger, light and manual measurements. Automated telemetry and control are still development goals. The images on the project page are explicitly labelled AI concept visualisations.

The question I want to get right before switching anything automatically is this:

How do we tell the difference between a change in the living environment and a sensor sitting in the fog?

I'd value practical feedback from growers, aquarium keepers and embedded-systems builders:
• Where would you put the sensors?
• What failure would you test first?
• What must keep working without the network?
